# SHOW Star ⭐
Android video-editor starter app inspired by the workflow of mobile editors.

Included:
- Video picker
- Video preview/player
- Trim start/end
- Export edited clip to MP4
- Dark SHOW Star UI
- Tool panels for Music, Text, Effects, Filters, Speed

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run on an Android 7.0+ device.
4. Build > Build APK(s).

Note: This is an original app implementation; it does not copy proprietary Video Star code/assets. Music/effects/filter rendering can be expanded in later versions.
